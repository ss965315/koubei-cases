# 【口碑案例優化】各店案例管理

美加集團 品牌行銷部 內部工具，以 GitHub Pages 發佈。

- 網站：登入後瀏覽（分院帳號只看自己分院；總部帳號看全部，並可勾術前、術後、開卡後匯出修改）。
- 資料：`data.enc.json` 為加密檔，沒有帳號密碼無法讀取。
- 管理頁：網址加 `?admin=1`，資料存在管理者電腦的瀏覽器，匯入報表後按「發佈到網站」產生新的 `data.enc.json`。

⚠️ 這個 repo 公開，只能放程式碼與加密後的資料檔。絕對不要提交未加密的顧客資料、Excel 報表或照片（`.gitignore` 已擋下常見格式）。

對外使用案例素材前，須依醫療法醫療廣告相關規定另行審查。

外部套件：SheetJS xlsx 0.18.5、html2canvas 1.4.1、Google Fonts（Noto Sans TC）。
